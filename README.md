# 安卓手机怎么安装指纹浏览器？

安卓安装「指纹浏览器」，先在官网选 Android。下载页提供 ARM64 APK；先核对手机架构与系统兼容性。[官网下载](https://zwbrowser.com/download/)

## 从下载到第一次打开

1. 在手机打开下载页，确认显示的是 Android 安装包。
2. 等下载完成，从下载列表打开 APK，阅读系统展示的应用名称和安装提示。设备由公司管理时，使用管理员批准的安装渠道。
3. 安装后启动应用，找到首页环境卡片，确认哪个环境标有「当前」，再输入一个熟悉的网址。
[官网操作说明](https://zwbrowser.com/help/mobile/start/)

![手机首页的当前环境和搜索框](https://zwbrowser.com/images/mobile-guide-active-light.webp)

## 如果手机提示无法安装

先记录屏幕上的完整提示，再核对下载是否完成、设备是否兼容、是否已安装其他来源的同名版本。涉及已有数据时，先确认网站账号、环境和需要保留的内容，再处理旧版本。
